## 原生 Android 验收

环境：Android 16 模拟器、项目已有开发客户端，加载本工作树 Metro；API 与 Worker 使用独立数据库 `steward_agent_hardening_20260907`。本地验收数据与原开发／测试库隔离。

| 流程 | 结果 |
|---|---|
| 手机号登录 | 原生输入与登录通过，开发验证码自动填入 |
| 任务创建 | 原生输入 → 真实模型建议 → 点击确认通过；修复后的任务响应经正式 Client 校验通过 |
| 图片 | 原生相册选择 → 图片预览 → 上传 → 模型解析 → 原生保存通过；该次模型给出任务与笔记两个候选，实际保存两项 |
| 断网恢复 | 请求受理后切断验收代理；页面显示恢复提示并保持等待；轮次数只从 1 增到 2；恢复至 1.5 秒延迟后建议自动出现 |
| 拆分限制 | 原生取消两项后仅剩 1 项，确认禁用、拒绝启用；随后可拒绝建议 |
| 录音 | 已触发并操作 Android 录音权限；合成麦克风正向验收受 SDK 故障阻塞，不能标记通过 |

录音阻塞证据：SDK `injectAudio` 在两次模拟器进程中均触发 `qemu-system-aarch64` 的 SIGSEGV，栈为 `audio_forwarder_enable → QemuAudioInputEngine::start → EmulatorControllerImpl::injectAudio`。已停止重试并恢复 AVD，未擦除数据。没有采集真实环境声音。iOS 未验收：当前机器无可用 Xcode／simctl。

## 发布与功能边界

本次修复留在独立工作树。生产完整复验需在正式工作流部署修复后的 API／Worker、执行向前迁移，并让 App 使用更新后的 Client／Zod 契约；未从本机发布生产或 OTA。
