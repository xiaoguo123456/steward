## 1. 品牌决定

产品对外名称统一为“序事”。“序”代表把零散信息整理成顺序、结构与下一步；“事”覆盖任务、日程、笔记、记录和生活中的大小事项。“序事”也与“叙事”同音，表达产品在长期使用中帮助用户看见生活脉络，而不只是维护一张待办清单。

品牌表达应让用户感到安静、可靠、有分寸。AI 是整理能力，不是产品人格的全部；产品必须清楚区分用户原话、AI 推断和已经保存的正式内容。

标题空间不足时只使用“序事”，不要缩写为“序”、拼音或英文名。正文首次出现可以写“序事 App”，后文统一写“序事”或“App”。“清单”是产品内的业务功能名，不能代替品牌名。

## 3. 产品定位

序事是一款面向个人的 AI 生活整理工具。用户可以通过文字、语音和图片说出或提交眼前的事情，由产品整理为可编辑的任务、日程、笔记、清单和结构化记录；涉及保存和修改时，由用户确认后执行。

核心价值按以下顺序表达：

1. 降低记录门槛：用户先自然表达，不必先判断应该放进哪个模块。
2. 给出清晰下一步：把杂乱输入整理成用户看得懂、能修改的候选结果。
3. 建立长期秩序：让分散的事项、记录和复盘形成连续脉络。
4. 保留用户控制：AI 的推断可见、可改、可取消，未经确认不写入正式数据。

## 4. 语气与用词

### 4.1 应当保持

- 简洁具体：优先说明现在发生了什么、用户可以做什么。
- 平静克制：不制造焦虑，不用夸张承诺催促用户。
- 有行动感：使用“整理”“确认”“下一步”“稍后继续”等明确动词。
- 诚实透明：AI 不确定时直接说明，并允许用户修正。
- 轻微陪伴感：像可靠的生活助手，不扮演亲密关系或权威专家。

### 4.2 推荐表达

| 情况 | 推荐表达 | 避免表达 |
|---|---|---|
| AI 已完成解析 | 已整理成 3 项，确认后保存 | AI 已经替你全部处理好了 |
| 信息不足 | 还缺少时间，要现在补充吗？ | 我不明白，请重新输入 |
| 保存前 | 检查一下，确认后会加入日程 | 已自动加入日程 |
| 错误状态 | 暂时无法保存，内容已保留，可以稍后重试 | 系统异常／未知错误 |
| 能力介绍 | 帮你整理任务、日程、笔记与记录 | 全能 AI 管家／什么都能管 |

不得使用“绝不遗漏”“完全准确”“读懂一切”“替你决定”等无法验证或削弱用户控制感的表述。涉及医疗、财务、法律等信息时，不得把整理建议表达为专业结论。

## 5. 视觉与内容方向

当前品牌采用安静、清晰、轻量的视觉方向。产品界面继续使用深绿 `#07865F`、`#047857` 与浅绿 `#ECFBF3` 承载主要操作和状态；品牌图标与 AI 管家使用瓷白 `#FCFCFA`、珊瑚橙 `#FB7753`、日光黄 `#FCCE47` 和深可可棕 `#3B2D28`，形成一致的暖色识别家族。暖色识别色不替代界面的功能色，避免大面积橙黄削弱信息层级。视觉设计服务于内容层级与可操作性，不把“AI 感”理解为高饱和渐变、发光装饰或拟人机器人。

图片和商店素材优先展示真实使用结果：一句自然输入如何变成任务、日程或记录，以及用户如何检查和确认。避免只展示抽象科技图、聊天气泡堆叠或无法在产品中完成的能力。

品牌名应使用完整中文“序事”，字间不插入空格。未经专门设计评审，不自行制作英文副标、变形字标或给品牌名增加固定图形组合。

### 5.1 App 图标

App 图标采用“序列折径”符号：一条连续纸带经过两次折转，将零散输入收束成稳定顺序；珊瑚橙外面与日光黄内面沿用 AI 管家的叠页配色，表达用户输入被接收、整理并形成结果。符号不直接添加眼睛、嘴或四肢，也不使用对勾、复选框、日历、机器人、聊天气泡或星光，避免退化为卡通宠物、通用待办或泛 AI 图标。

- 图标底色固定为瓷白，允许从中心 `#FCFCFA` 到边缘 `#F3F4F2` 的极轻冷灰过渡；主符号保持珊瑚橙外页、日光黄内折面，并只在折痕最深处使用少量深可可棕。
- 正式图标保留克制的纸张纹理、折面明暗和贴近折痕的环境阴影，不增加文字、玻璃高光、厚重投影或多色科技渐变。
- iOS、Android Adaptive Icon、Android 单色主题、启动图和 Web favicon 使用同一几何母版。
- 高分辨率图标与透明前景母版位于 `apps/mobile/assets/brand`；`apps/mobile/assets/images` 中的 PNG 是构建使用的派生产物，统一由 `brand:render` 生成。
- App Store 使用无透明通道的 1024 × 1024 `apps/mobile/assets/images/icon.png`；Google Play 上传素材使用 512 × 512 `apps/mobile/assets/store/google-play-icon.png`。

## 6. 技术标识边界

本次改名只改变用户可见品牌，不迁移已经参与构建、签名、接口或部署的稳定技术标识。以下名称继续保留：

| 类型 | 保留值 | 原因 |
|---|---|---|
| 仓库与 workspace 标识 | `steward`、`ai-steward`、`@steward/*` | 避免破坏依赖、脚本和自动化 |
| Android 包名 | `com.aisteward.mobile`、`com.aisteward.mobile.test` | 保持应用身份和签名升级链路 |
| URL Scheme | `aisteward`、`aisteward-test` | 保持深链兼容 |
| 环境变量前缀 | `STEWARD_*` | 保持 CI 与生产 Secrets 兼容 |
| Expo slug、频道与项目标识 | 现有 `ai-steward`、`steward-*` 及 Project ID | 保持 EAS、OTA 和已配置凭据兼容 |
| 代码类型与变量名 | 现有 `Steward*` 等稳定标识 | 不为纯品牌改名制造无业务价值的契约变更 |

这些值只出现在开发、运维或系统集成场景，不作为面向用户的产品名称。新增用户可见文案不得再使用旧品牌名。

## 7. 发布与治理

- App 桌面名称、启动与锁定提示、后台标题、公开 H5、帮助中心和应用商店资料统一使用“序事”。
- 隐私政策、用户协议、个人信息与第三方清单中的产品名称同步更新；运营主体保持“琼海绘象图数字科技有限公司”。
- 应用商店截图、介绍文案、官网或社交账号上线前，按本规范复核名称、口号与能力边界。
- 当前命名基于产品语义与公开信息的初步筛选，不等同于商标注册或法律检索结论。正式商业推广前应完成第 9 类、第 42 类等相关类别的商标近似检索与注册评估。
- 未取得注册商标前，不使用 `®`，也不对外声称“序事”为注册商标。

## 8. 自检清单

发布任何用户可见内容前确认：

- 品牌名是否完整写作“序事”，没有混用旧名称或把“清单”当成 App 名。
- 是否先讲用户价值，再讲 AI 技术。
- 是否准确描述“AI 生成候选、用户确认后保存”的边界。
- 是否避免无法验证的绝对化承诺和未上线能力。
- 法律文本、商店资料、帮助页面和当前 App 行为是否一致。
- 技术标识是否保持兼容，没有因品牌文案调整而误改包名、Scheme、Secret 或 API 字段。
