# Agent 意图恢复与响应优化验收

日期：2026-09-07。实现提交：`91c1ad4`、`9ead692`、`b053845`；性能复测固定使用 `b053845`。本次在独立工作树与数据库 `steward_agent_hardening_20260907` 完成，未发布生产。

## 已完成的修复

| 原有问题 | 当前行为 |
|---|---|
| 乱码、纯空白、不可见字符 | 服务端拒绝空及全不可见输入；乱码进入不行动或澄清，不默认创建记录。原生输入同样阻止全不可见提交。 |
| 模糊或非法日期 | 日期、时间分别携带原话证据，Go 计算实际值；不擅定小时，不顺延非法日期。相对日期锚定原消息发送时间，跨午夜补答不漂移。 |
| “提醒我”缺时间 | 先补充关键提醒时间；不能静默降级为无日期任务。普通任务只缺可选日期时直接生成建议。 |
| 重复目标与条件不成立 | 查询真实同名对象，包含已完成任务；提供有日期／状态的真实选项。建议生成与确认时都检查条件、归属和版本。 |
| 互斥要求 | 未解决的同字段冲突阻止生成建议，不能一边指出冲突一边准备修改。 |
| 撤回、偏好纠正 | 当前对话待确认建议作为服务端快照；明确撤回经事务真实拒绝建议。撤回偏好不连带取消任务。 |
| 修订旧建议 | 原子替换旧版本，旧卡片失效；不把未保存的建议当成正式任务修改。 |
| 多轮补答 | 澄清意图、缺失字段和真实选择持久化；缺标题的明确创建入口不依赖模型提问。补齐后避免重复追问，换话题结束旧问题。 |
| 假完成与工具纠错 | 建议和取消说明依据实际提交结果。Schema 反馈只含声明字段及约束；针对无动作的完成声明有界纠正，失败标记降级。 |
| 不支持的删除被替换成完成 | 删除请求不能静默生成任务状态修改；保留列表／详情的正式手工路径。 |
| Capture 否定输入 | 用户直接说随口聊、不保存时零候选正常结束，状态为 `discarded`；不会自动改成笔记，也不展示待确认零条的错误状态。媒体中引用的指令仍按资料处理。 |
| 可见结果等待 | 成功的简单建议省去一次模型复述；复杂请求继续编排。SSE 明确完成后立即读取权威结果，断线仍由轮询恢复。 |
| 工具上下文与媒体耗时 | 明确单一写入意图只保留相关建议能力及全部只读工具；不扩大授权，澄清／待处理建议／复合表达保留全集。多媒体预处理并发上限为 2，顺序、失败与取消语义保持一致。 |

载体决策：核心交互保持 React Native，本次不新增 H5、权限、SDK 或第三方处理者；没有新增需要发布的隐私／法律页面。网络契约增加可选的消息交互结果及澄清选择字段，OpenAPI、生成 Go／TypeScript／Zod、Fixture、后端与原生适配已同步。新增迁移 `00056` 保存权威交互状态。

## 无意义、模糊与多轮回归

原始 37 个场景重复两次，共 **84 次观测，自动断言标记问题为 0**；旧基线为 15/84。另有 12 个场景的独立措辞回归，共 **32 次消息观测，标记问题为 0**。两组都保留同一场景内的连续历史和待确认建议，并检查正式任务没有未经确认的新建或更新。

原始集与独立措辞集在来源传递修复后串行重跑；“先做再查”等复合表达的继续编排范围另有独立 Race 单测。独立措辞集已用于开发期发现并修复问题，现为回归集，不再称为未经调优的盲测集。

中间运行再次发现了可选日期阻塞、删除转成完成、标题续答重复追问，以及工具裁剪暴露的来源不可见，均先保留反例再增加服务端保护，没有改成更宽松的成功断言，也没有更新 Eval 基线掩盖退化。

这些是有限的定向样本，不能推断线上失败率。自然语言回复的所有语义尚不能由自动断言穷尽；一般澄清仍依赖模型遵守工具协议。人工阅读还发现个别拒绝类回复会提及尚不支持的批量清理／归档能力，没有生成相关建议或发生写入；自由文本的能力承诺仍需增加语义评测，不能将本轮自动断言全绿等同于回复完全正确。必须持续记录“错误建议、补答后缺建议、降级、旧建议残留”，不能只统计 Operation 成功。

证据：[原始回归](reviews/agent-intent-2026-09-07/原始场景回归.json)、[独立措辞回归](reviews/agent-intent-2026-09-07/独立措辞回归.json)、[可选日期反例](reviews/agent-intent-2026-09-07/工具裁剪中间失败样本.json)、[删除反例](reviews/agent-intent-2026-09-07/删除语义中间失败样本.json)、[标题续答反例](reviews/agent-intent-2026-09-07/标题续答中间失败样本.json)。

工具裁剪后的中间 HTTP 基准中，修改／拆分共 6 次未生成建议，原因是实际来源只保存在审计元数据，工具文本没有提供 source_refs。修复为随只读结果传递真实引用，结果截断仍保留来源，来源校验没有放宽。查询、新建、改期、拆分、日程、偏好等 7 类真实模型验收随后通过，其中 5 类写入完成了正式确认闭环，见[正向确认闭环结果](reviews/agent-intent-2026-09-07/正向确认闭环.json)。保留[这轮完整失败基准](reviews/agent-intent-2026-09-07/来源不可见中间性能失败样本.json)，不将失败请求算成提速。

## 原生 App、弱网与确认

在 Android 模拟器的原生开发包实际点击完成：创建“买验收牛奶”建议，发送“算了，不要了”撤回；创建两条有不同截止日期的“意图验收周报”，点击第一条真实消歧选项；请求受理后断开代理连接，Worker 继续处理，恢复网络后取得建议并点击“确认执行”。

确认结果：选中任务从 9 月 12 日改成 9 月 8 日；另一条仍为 9 月 10 日。确认后旧选项不可再次点击。两条虚构任务随后通过正式 API 删除，目标任务版本包含修改及删除的推进，另一条仅推进删除版本。

本段原生验收在 `91c1ad4` 的交互实现完成；后续提交没有修改原生或网络契约，补充的是后端意图保护与工具裁剪。弱网通过本地代理主动断线模拟，不能替代各运营商与真机网络矩阵。

## 响应时间复测

环境为本地 API → River Worker → 真实 Provider，chat／parse／vision 使用 qwen3.8-flash，ASR 使用 qwen3-asr-flash，关闭思考。每类 3 次，另有一次暖机排除；同类每次新建对话，串行执行，期间不并行运行模型回归。图片为合成中文 PNG，语音为 7.68 秒、16 kHz、单声道 PCM WAV，混合输入各含一段文字、一张图和一段音频。

下表为取得权威结果的秒数，不是首字，也不是原生渲染耗时；上传及录音不计入结果耗时，上传另有记录。每类只有 3 次，不推断生产 p95 或并发容量。前后调用发生在不同时段，Provider 抖动与输出长度会影响结果，不能把所有差值都归因于代码。

本轮 **36/36** 取得预期形态的结果。修改任务和创建日程各出现一次参数校验拒绝，模型修正后均成功，仍会带来额外等待；旧基线为 **35/36**，旧拆分 3 次中有 1 次无建议。因此旧拆分表格的 6.15 秒包含失败，不能作严格成功耗时对比；旧拆分仅成功两次的中位数为 5.52 秒。

简单建议省去最终复述，明确创建的工具定义上下文缩小；拆分／修改仍需真实检索及版本来源校验。图片和语音并行只能压缩预处理部分，结构化解析仍需模型；单图、短语音、混合输入的整体时间还受 Provider 波动与输出量影响。查询仍有两次模型往返，是后续继续优化和监控的重点。生产需要持续记录首段文本、权威结果就绪、模型往返数、降级和错误建议，不能只看平均延迟。

## HTTP 状态验收

最终版本通过生成 Client 调用真实 API／Worker，结果如下：

- 空字符串、普通空白、不可见字符均返回 `400 / VALIDATION_FAILED`。
- 乱码进入 `awaiting_instruction`，零候选、一个阻塞问题；补充明确任务后 revision 推进，进入 `needs_confirmation`，无遗留问题。零候选的提前确认被参数校验拒绝，不把它当作 Domain 门禁证明。
- 开会 10:00 开始、09:00 结束时，存在真实 Event 候选与阻塞问题；提前确认返回 `CAPTURE_NOT_READY`。补答正确结束时间后 revision 推进，进入可确认状态，无遗留问题。
- “不要记任务，只是随口说”及“明确不保存任何记录”均正常结束为 `discarded`，零候选、零阻塞问题。

见[HTTP 原始结果](reviews/agent-intent-2026-09-07/HTTP澄清与空输入.json)。脚本通过正式 API 丢弃自身 Capture；虚构任务、待确认建议、对话与媒体也按各自验收脚本清理，审计保留在隔离库，临时登录文件在收尾删除。
