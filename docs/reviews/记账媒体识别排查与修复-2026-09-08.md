# 记账媒体识别排查与修复

日期：2026-09-08。仅使用虚构小票和合成语音，不记录原始媒体、凭据或真实用户正文。

## 问题与修复

1. 拍照记账复用通用任务输入提示，并自动弹键盘遮挡图片来源入口。改为记账示例、选图后的可选备注提示，进入时不自动弹键盘。保持原生流程，无新增权限、SDK、H5 或个人信息用途。
2. 纯语音从记账入口提交也要求“识别票据”。改为按本次输入生成待确认记账记录。
3. 真实图片和语音均可能输出中文 `direction`，而旧月报只统计 `income`／`expense`，造成漏算。Trackers Domain 在手工及 AI 创建、更新时统一处理明确的中文收支值；未知方向和非正金额拒绝。移动端兼容历史中文值，防止既有记录漏算。
4. 小票明确的交易时间被遗漏，最终使用识别时刻。`capture-parse@v9` 补齐 timestamp 示例，并约束交易时间、实付金额及收支机器值。沿用 v6 Schema、RecordValue、timestamp 和已有错误码，没有新增网络字段或数据库列，无需迁移或重新定义 DTO。
