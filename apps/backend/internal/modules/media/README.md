# 媒体模块

本模块拥有媒体资产元数据、直传授权、上传完成校验和对象删除。二进制内容始终位于
私有对象存储，数据库只保存用户隔离的对象键与真实元数据。

- `POST /v1/media/upload-grants` 使用请求幂等键；服务端只把 `media_id` 列表写入幂等快照，
  不保存签名 URL。同键重放复用同一媒体记录并重新签发短期地址。
- `POST /v1/media/{media_id}/upload-grant` 只为当前用户仍为 `pending` 的同一媒体重新授权。
- 上传完成由服务端回查对象存储的大小、类型与内容摘要，不信任客户端声明。
- Capture 离线队列只持久化稳定幂等键和 `media_id`，不持久化任何上传或读取签名地址。
