# 亲友模块

## 职责

本模块拥有用户主动建立的 `Person`、已经发生的 `PersonInteraction`，以及人物与正式 `Event` 的关联。

## 边界

- 首版只提供手动添加，不申请整本通讯录权限，也不读取聊天、通话或邮件。
- 未来计划、生日和纪念日继续复用 `Event`；人物删除时只删除关联，不删除 Event。
- 已经发生的见面、电话和消息记录为 `PersonInteraction`，不伪装成日程。
- 所有读写都在当前用户的 RLS 事务内执行；创建和删除使用幂等键，修改使用 `If-Match`。
- AI 只可检索人物并生成待确认的关联事件 Proposal，不得直接创建人物或写数据库。
