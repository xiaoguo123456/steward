# 亲友模块

## 职责

本模块拥有用户主动建立的 `Person`，以及人物与正式 `Event`／`Task` 的关联。

## 边界

- 首版只提供手动添加，不申请整本通讯录权限，也不读取聊天、通话或邮件。
- 未来计划、生日和纪念日继续复用 `Event`；人物删除时只删除关联，不删除 Event。
- 为某人准备的事项继续复用 `Task` 并保留原 TaskList 归属；`task_people` 只保存额外关联，人物删除时不删除 Task。
- 所有读写都在当前用户的 RLS 事务内执行；创建和删除使用幂等键，修改使用 `If-Match`。
- 当前 AI 不读取人物资料，也不生成关联 Task Proposal。以后开放必须有单独授权、最小字段、同名消歧、来源和用户确认，不得直接创建人物或写数据库。
- 早期 `PersonInteraction` 读写接口和数据表仅用于已发布旧版 App 的兼容窗口；OpenAPI 已标记弃用，新客户端不得接入，后续通过向前迁移移除。
