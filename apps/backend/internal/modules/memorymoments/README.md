# 时光模块

## 职责

拥有用户主动发布的私人照片时光，包括按自然日查询、详情读取、发布与整段删除。
它与 AI 长期记忆模块的 `memory_items` 完全独立，不共享表、DTO 或状态机。

## 不可变边界

- 发布请求一次性写入日期、照片顺序、标题和故事。
- 契约与服务端均不提供更新操作；发布后只能整段删除，再重新发布。
- 删除事务同时让时光和对应媒体引用不可见，并在 Retention 队列登记每张图片的对象存储清理；临时失败由同一任务幂等重试，不影响系统相册中的原文件。
- 所有查询和写入均在带 `app.user_id` 的事务中执行，并由 RLS 二次隔离。

## 媒体与 AI 边界

- 只接受当前用户已完成上传的图片 `media_id`，读取时返回短期私有地址。
- 当前产品决策不把照片或正文发送给 AI，也不展示确定性假候选。
- 后续若增加文案或图像理解，必须先补齐单独同意、第三方处理者清单、
  `memory_moment_writing_candidate` Schema、审计与 Eval；AI 只能返回 Candidate，
  用户确认后仍通过本模块的正式发布 Command 写入。
