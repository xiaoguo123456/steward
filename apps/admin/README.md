# 序事管理后台

内部运营 Web，复用 Ant Design、React Query 和生成的 Admin Client；不嵌入 App。
入口为 `/admin/`，本地运行 `pnpm admin:dev`，Go Admin API 默认使用 8788 端口。
账号、Cookie 和数据库角色与用户端独立。密钥配置见 `docs/部署说明.md`。

## 当前交付

- 管理员手机号白名单、首次验证码验证后设密、密码／验证码登录和验证码重设密码。
- 认证接口使用生成 Client 与 Zod 校验；名单、验证码与 Cookie 均独立于 App。

- 总览、使用分析、成本页支持报表时区下的自然日范围；金额统一人民币 CNY，价格使用 `unit_price_cny`。
- 用户列表支持用户 ID、完整手机号精确匹配、账号状态和初始化筛选。
- 用户详情展示数量与状态，支持预算回填、暂停／恢复、会话撤销及管理原因。
- 处理记录与管理记录支持游标翻页。
- 所有正式请求的会话失效统一清除会话、CSRF 和缓存；写操作禁止并发提交，
  结果未知时同一表单重试使用原幂等键，版本冲突后刷新并要求重新确认。
- 失败页面提供重试，缺价不显示为免费，失败统计分区不显示虚构的零。

后台身份验证采用确定性规则，不新增 AI 授权能力，不读取用户正文。
手机号登录已同步 Admin OpenAPI、生成 Go／TypeScript／Zod、sqlc 与 Fixture；
App 无对应认证适配。已有运营修复的预算展示使用 `ai_budget`，任务详情仅调整原生展示。
完整检查范围、已确认的线上故障和剩余缺口见
`docs/reviews/后台运营验收-2026-09-08.md`。
手机号登录、名单维护及认证验收见 `docs/reviews/后台手机号认证验收-2026-09-08.md`。
