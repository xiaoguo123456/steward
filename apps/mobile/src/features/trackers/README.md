# 打卡前端

## 页面

- `(tabs)/data` 打卡首页：今日待打卡、我的打卡、最近记录，右上角进管理。
- `/trackers/new`（DAT-01）创建打卡项：可以让助理描述生成，也可以自己编字段。
- `/trackers/[id]`（DAT-02）打卡项详情：最近值与变化、记录列表、字段与管理入口。

## 约定

- 内置打卡项（`builtin_key` 非空）不显示改字段与删除入口，只能改名、归档。
  服务端也拦着同样两件事——界面藏起来不算保证，契约边界才是。
- Record 的发生时间用当地写法「2026-08-19 09:30」输入，提交时转 ISO。
  给用户看带 Z 的字符串只会让人算不清自己记的是几点。
- 编辑已有 Record 时，Schema 里已删掉但这条记录里还有值的字段仍然显示，
  否则用户会在不知情的情况下把它们抹掉。
- 字段 `key` 只在新增那一刻定下来，改字段名不跟着改：
  历史 Record 的值是按 key 存的。

## 不做

- 不在客户端做单位换算，数值原样提交。
- 不本地推断「今天有没有打卡」以外的任何状态；统计与聚合都走服务端。
