# 专注前端原型

## 范围

本模块对应功能规格 8.2、产品设计 9.2 与架构设计 3.3.1 的“番茄钟”生活场景入口。当前实现 Expo 前端原型，覆盖开始前设置、专注进行中、想法暂存、休息、完成确认和专注记录。

## 页面与状态

- 准备：选择番茄钟或正向计时、关联今日 Task、设置 25／45／60 分钟或自定义时长。
- 专注：以计时器为唯一视觉中心，提供暂停、继续、结束确认和“记下想法”。
- 休息：默认 5 分钟，允许暂停、延长或跳过；每 4 轮长休息尚未实现。
- 完成：确认任务进度与本次状态后，用户主动保存本地专注记录。
- 记录：展示今日和近七天摘要，以及按时间倒序的本地记录。

## 数据边界

- 今日任务来自现有 Task Fixture，只作为本次专注的关联对象，不复制 Task 领域类型。
- 专注记录、想法和任务完成选择均为 App 进程内的本地预览状态；关闭进程后不保证保留，也不会修改首页 Task。
- “保存专注记录”是明确确认动作，但当前不会写入正式 Tracker／Record。
- 正式接入时必须新增对应 Tracker Schema 与网络契约，并通过生成的 API Client、Zod 校验和服务端确定性时间语义写入；本地 `FocusRecord` 不得直接提升为网络 DTO。

## 视觉与组件

- 复用 App 的白色画布、品牌绿、浅灰功能面、公共圆角和文字层级，不创建独立的番茄钟色板。
- 休息态只使用现有中性色降低强度；危险色仅用于结束专注。
- 计时环由 React Native 基础视图组成，不新增绘图库或原生依赖。
- 通用操作图标统一通过 `components/ui/icon` 使用成熟图标库，不维护手绘 SVG。
