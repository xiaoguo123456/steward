# 专注前端模块

## 范围

本模块对应功能规格 8.2、产品设计 9.2 与架构设计 3.3.1 的“番茄钟”生活场景入口，覆盖开始前设置、专注进行中、想法暂存、休息、完成确认和专注记录。

## 页面与状态

- 准备：选择番茄钟或正向计时、关联今日 Task、设置 25／45／60 分钟或自定义时长。
- 专注：以计时器为唯一视觉中心，提供暂停、继续、结束确认和“记下想法”。
- 休息：默认 5 分钟，允许暂停、延长或跳过；每 4 轮长休息尚未实现。
- 完成：确认本次状态后，用户主动保存专注记录。
- 记录：展示今日和近七天摘要，以及按时间倒序的正式记录。

## 数据边界

- 可关联任务来自正式 Today API，只读取服务端返回的 Task 引用，不复制 Task 领域类型。
- 用户点击“保存专注记录”后，通过生成 Client 写入内置 `builtin_key=focus` Tracker 的 Record；列表和统计读取同一份正式数据。
- 计时、暂停、休息状态和暂存想法只属于当前页面会话，不自动创建 Note、Task 或 Capture。
- 当前 Record 只保留关联任务标题，不复制 Task 状态；专注完成不会自动完成关联 Task。
- 本地 `FocusRecord` 是展示模型，不是网络 DTO。时长以分钟写入，服务端仍负责 Tracker Schema 校验和时间语义。

## 视觉与组件

- 复用 App 的白色画布、品牌绿、浅灰功能面、公共圆角和文字层级，不创建独立的番茄钟色板。
- 休息态只使用现有中性色降低强度；危险色仅用于结束专注。
- 计时环由 React Native 基础视图组成，不新增绘图库或原生依赖。
- 通用操作图标统一通过 `components/ui/icon` 使用成熟图标库，不维护手绘 SVG。
