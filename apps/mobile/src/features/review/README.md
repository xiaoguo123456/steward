# 复盘前端原型

当前模块实现首页“复盘”入口对应的每周回顾前端原型，定位为可快速阅读的一页式 AI 报告，不使用数据看板或聊天窗口作为主结构。

## 当前交互

- 默认展示最近一个完整自然周；点击顶部周期选择器后，从底部历史周列表切换快照。顶部返回箭头只负责离开页面，不与周期切换共用箭头语义。
- 先显示 AI 周总结，再显示由确定性数据形成的紧凑概览。
- AI 观察最多 3 条，来源默认收起，用户点击“查看依据”后再展开任务、专注或打卡入口。
- 下周建议使用单层轻量列表，点击后查看具体任务、字段变化和来源，再确认加入计划。
- 个人感受作为页面末尾的折叠次级入口；当前补充只保存在前端进程内。

## 当前边界

本模块使用本地 Fixture 验证信息结构和交互，不连接 Review API，不生成真实 AI 内容，也不会修改正式 Task、Event、Record 或 Review Snapshot。

正式接入时：

- 数据概览由 Go Domain 按固定口径计算，AI 不重新计算指标。
- AI 只输出结构化的总结、观察和建议，每条内容必须携带合法来源引用。
- 页面通过生成的 TypeScript API Client 读取快照、刷新状态和来源，不手写网络 DTO。
- 接受建议必须进入正式确认事务，明确展示目标 Object、字段和值；AI 不直接写数据库。
- 数据不足时省略无依据的观察；AI 失败时仍保留确定性数据概览。
