# 复盘前端模块

当前模块实现首页“复盘”入口对应的正式每周回顾，定位为可快速阅读的一页式 AI 报告，不使用数据看板或聊天窗口作为主结构。

## 当前交互

- 默认展示最近一个完整自然周；点击顶部周期选择器后，从底部历史周列表切换快照。顶部返回箭头只负责离开页面，不与周期切换共用箭头语义。
- 先显示 AI 周总结，再显示由确定性数据形成的紧凑概览；任务的完成、新建、逾期固定排成三列，笔记与打卡固定排成两列，窄屏不产生孤立指标。
- AI 观察最多 3 条，来源默认收起，用户点击“查看依据”后再展开任务、专注或打卡入口。
- 下周建议使用单层轻量列表，点击后查看具体任务、字段变化和来源，再确认加入计划。
- 个人感受作为页面末尾的折叠次级入口；确认后保存为带“复盘”标签的正式 Note，不写入可重建的 Review Snapshot。

## 当前边界

- 页面通过生成 Client 读取 Weekly Review；数据概览由 Go Domain 按固定口径计算，AI 不重新计算指标。
- AI 小结通过异步 Operation 生成，只输出结构化标题、摘要、重点和带合法来源的建议；没有足够指标时不调用模型。
- AI 不可用或生成失败时仍展示确定性数据概览，不用空白 AI 区块遮住真实指标。
- 待确认的下周调整复用正式 Action Proposal；用户确认后才由 Go Command 写入，页面不直接修改目标 Object。
- 周期选择和指标格式化是展示逻辑，不建立第二份 Review 网络 DTO，也不在客户端补零或重算环比。
